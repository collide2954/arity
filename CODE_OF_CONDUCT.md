# Code of conduct

We want arity to be a good place to work for all people.

## What we expect

- Be respectful to all people, in all project spaces.
- Discuss the work, not the person.
- Accept correction of your work. Correct errors in the data and in the code
  without blame.
- Give credit to the work of other people.

## What we do not accept

- Harassment, insults, or threats.
- Discrimination of any kind.
- Publication of private information about a person without permission.

## How to report a problem

Write to the maintainers in private. Use the contact information on the GitHub
profile of a maintainer. If you cannot find it, open an issue that asks for a
private contact. Do not put details of the problem in that issue.

The maintainers keep each report confidential. They can remove content,
give a warning, or block a person from the project.
