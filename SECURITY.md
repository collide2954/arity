# Security policy

## Supported versions

arity is in early development. Only the latest commit on the `main` branch
receives security corrections.

## How to report a vulnerability

Do not open a public issue for a vulnerability.

1. Go to the **Security** tab of the repository.
2. Select **Report a vulnerability**.
3. Describe the problem and the steps that show it.

We reply within 7 days. We tell you when the correction is available.
