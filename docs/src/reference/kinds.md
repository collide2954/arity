# Entity kinds

<!-- The tests of arity-protocol write this file. After a change, run them with ARITY_UPDATE_DOCS=1. -->

Each entity has one of these kinds. `arity vocab kinds` prints this list.

| Kind | Meaning |
| --- | --- |
| `chemical` | An element, molecule, ion, drug, mixture, or solution. |
| `material` | A solid material or a material sample, for example an alloy, a polymer, or a thin film. |
| `gene` | A gene or a genetic locus. |
| `protein` | A protein, peptide, enzyme, or antibody. |
| `nucleic_acid` | An RNA or DNA molecule that is not a gene, for example an mRNA, a microRNA, or a plasmid. |
| `organism` | A taxon, species, strain, or cultivar. |
| `cell_line` | A named cell line, for example HeLa. |
| `cell_type` | A type of cell, for example a hepatocyte. |
| `anatomical_entity` | An organ, tissue, body part, or cell component. |
| `disease` | A disease or disorder. |
| `phenotype` | An observable trait, sign, or symptom. |
| `process` | A process or phenomenon, for example a pathway, a reaction, or a phase transition. |
| `physical_system` | A physical system, for example a particle, a nucleus, a plasma, or a star. |
| `device` | An instrument, apparatus, sensor, or implant. |
| `environment` | An environmental material or setting, for example soil or seawater. |
| `population` | A group of people or animals, for example a cohort. |
| `procedure` | An intervention or procedure, for example surgery, a diet, or irradiation. |
| `other` | A thing that no other kind describes. |
