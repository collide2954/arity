# Notice kinds

<!-- The tests of arity-protocol write this file. After a change, run them with ARITY_UPDATE_DOCS=1. -->

arity gives each notice one of these kinds, and it keeps the type name that the source uses. `arity vocab notices` prints this list.

| Kind | Name |
| --- | --- |
| `retraction` | Retraction |
| `partial_retraction` | Partial retraction |
| `withdrawal` | Withdrawal |
| `removal` | Removal |
| `expression_of_concern` | Expression of concern |
| `correction` | Correction |
| `erratum` | Erratum |
| `corrigendum` | Corrigendum |
| `addendum` | Addendum |
| `clarification` | Clarification |
| `new_version` | New version |
| `new_edition` | New edition |
| `reinstatement` | Reinstatement |
| `other` | Other notice |
